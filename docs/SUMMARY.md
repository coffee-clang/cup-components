# Documentation

`cup-components` builds and packages development tools for `cup`. Start with the specification for the producer model, then use the focused documents for package internals, build operation and dependencies.

- [Specification](SPECIFICATION.md) — supported tools and platforms, host/target semantics, package identity and the producer contract.
- [Packages](PACKAGES.md) — package contents, metadata, manifest, archives, relocatability and runtime dependency closure.
- [Build](BUILD.md) — workflows, direct builder interfaces, build phases, tests, outputs and publication behavior.
- [Dependencies](DEPENDENCIES.md) — dependency categories, builder environments and upstream source inputs.
